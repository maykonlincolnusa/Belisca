RECOMENDADO N° 1 PARA PETISCOS
amazon/chronos-2
Time-Series Zero-Shot

Amazon Chronos-2 & Chronos-Bolt

Modelo foundation pré-treinado baseado em Transformers que converte séries temporais em tokens. Ideal para previsão probabilística (quantis P10, P50, P90) de porções de petiscos para o fim de semana e compras exatas de insumos perecíveis (batata, carnes, óleo).

✓ Suporta covariáveis externas (feriados, clima de chuva, dia de futebol).
✓ Calcula estoque de segurança exato com 95% de nível de serviço.
✓ Versão amazon/chronos-bolt-base tem inferência ultra-rápida em CPU.
Python / transformers 
from chronos import Chronos2Pipeline
pipeline = Chronos2Pipeline.from_pretrained("amazon/chronos-2")
forecast = pipeline.predict_df(vendas_historico_df, prediction_length=4)

Google TimesFM 2.0 (PyTorch)

Foundation model do Google para previsão de séries temporais de alta frequência. Excelente para prever o fluxo de pedidos por hora (curva de almoço e curva de happy hour noturno no delivery).

✓ Previsão multivariada de pedidos por hora.
✓ Otimiza escala de equipe na cozinha e fritadeiras.

Prior-Labs/TabPFN-v2-clf
In-Context Tabular

TabPFN v2 (Prior Labs)

O modelo de Transformer mais avançado para dados tabulares do mundo. Executa previsões instantâneas em 1 segundo sem necessidade de treino ou tuning de hiperparâmetros.

✓ Classificação de Risco de Ruptura: prevê se o insumo vai acabar no meio do sábado.
✓ Previsão de Atraso e Cancelamento por raio e forma de pagamento.
✓ Prior-Labs/TabPFN-v2-reg para regressão de margem financeira líquida.
Python / tabpfn
